# Targeted annotation cleaning

## Scope and command

Annotation cleaning corrects only preprocessing proven to discard valid rows or
misstate source semantics. It does not clip timestamps, reconcile sources, invent
identities, or derive model labels.

```text
source annotation
    ↓ explicit validation
minimal targeted transformation
    ↓
derived interim table
```

Run the maintained implementation with:

```bash
uv run conv-wm clean annotations
```

Generic orchestration and accounting live in `conv_wm.data.cleaning`. Dataset
rules live beside their declarations in `conv_wm.data.datasets.ego4d_cleaning`
and `conv_wm.data.datasets.egocom_cleaning`; each is registered through
`DatasetSpec.annotation_cleaner`. The discovery notebook remains historical
evidence and is not a production dependency. Ego4D is streamed directly from
the official train and validation JSON files; the historical `av.parquet` cache
is not read.

The command writes the configured interim Parquet files and
`${paths.reports}/cleaning/annotations/summary.json`. For every output the report
records source/output/removed counts, mutually exclusive removal reasons,
nullable-field retention, rule version, transformations, paths, parameters, and
shared execution provenance.

## Ego4D social annotations

The [official Ego4D annotation schema](https://ego4d-data.org/docs/data/annotations-schemas/)
declares talking `target` as nullable, `is_at_me` as a Boolean, and `person` as a
string. The [social benchmark description](https://ego4d-data.org/docs/benchmarks/social/)
defines talking-to-me as speech directed at the camera wearer and
looking-at-me as a visible person looking at the camera wearer. Cleaning
therefore preserves the release fields without expanding a null target into a
new semantic class.

The maintained talking population is 43,172 rows:

| `is_at_me` | Target available | Rows |
| --- | --- | ---: |
| `True` | yes | 7,136 |
| `False` | yes | 5,317 |
| `False` | no | 30,719 |

There are 2,791 rows with unknown speaker `person=-1`; they are retained. Two
additional retained rows use concrete person IDs absent from the clip's person
collection; annotation integrity reports that source inconsistency as a warning
and does not rewrite the IDs. The two rows removed during cleaning have no
person value at all.

Target availability is empirically asymmetric. Among rows whose speaker joins
the persons table, only 19 of 13,479 camera-wearer speech rows have a populated
target, versus 12,412 of 26,900 non-wearer speech rows. This is an observed
population property, not a guarantee that null means any particular addressee.

Looking is also not empty: 10,211 usable intervals remain. In the current
release all have `target=null` and `is_at_me=False`; four identity-less records
were removed. This payload conflicts with an intuitive positive-event reading
of the benchmark description, and the release changelog refers to a differently
named looking flag. The field interpretation is therefore unresolved. The
pipeline preserves the values and does not relabel them.

## Speech-source relationships

Voice activity remains the more complete activity source and transcription a
partial lexical enrichment. On the regenerated tables, voice→transcription
strict overlap is 86.7% and transcription→voice is 89.3%. Restricting to known
transcription speakers raises the latter to 95.8%; a diagnostic ±0.5 s expansion
raises it to 97.1%, and clip-level matching reaches 97.2%. None of these
comparisons changes timestamps or identities.

Uncovered voice intervals are shorter than voice intervals overall: median
0.965 s versus 1.340 s, with 95th percentiles 5.038 s versus 7.393 s. This is
consistent with short vocalizations being less likely to receive lexical text;
it is not evidence that those voice segments are dirty. The
[official AV diarization repository](https://github.com/EGO4D/audio-visual)
treats voice activity and transcription as distinct annotations.

All-source talking→voice exact interval identity is 91.6%, and overlap is
93.3%; voice→talking overlap is 99.4%. For talking rows with a populated target,
exact identity is 96.7% and overlap is 99.6%. The historical 30.6%
voice→talking result now applies only to that explicit-target subset, not to the
full talking population.

## EgoCom source preservation

The ground-truth output preserves all 359,536 rows:

- 177,230 have both timestamps;
- 343 have a start but no end, all with nonblank content;
- 181,963 have neither timestamp, including 53,752 nonblank tokens;
- six have a null word value.

The 13,512 rows whose speaker has no own POV are valid and retained. The
cleaning report records `participant_has_own_pov` coverage as a diagnostic
(346,024 true, 13,512 false); the annotation integrity contract has no
participant-to-POV foreign-key warning because such a relation would
misrepresent the source.

## Deliberate preservation and boundaries

- Source timestamps remain untouched, including negative starts, overshoots,
  and track frames outside the effective clip range.
- Unknown identity sentinel `-1` remains unchanged.
- No transcript is manufactured and no voice segment is removed to force
  cross-source agreement.
- Downstream temporal projection may intersect a source interval with a valid
  media domain. That operation does not belong to source cleaning.
- No label/cue ontology, dense target, resampling, feature extraction,
  synchronization, or automatic temporal correction is implemented here.
